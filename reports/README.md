# SwiftShip Reports

Create these reports in Salesforce after deploying the objects.

1. **Delayed Shipments** — Shipment report; Status = In Transit or Out for Delivery.
2. **Open Exceptions** — Delivery Exception report; Status != Closed.
3. **Delivery Attempts** — Delivery Attempt report; group/filter by Attempt Status.
4. **Route Performance** — Route report; group/filter by Route Status.

Suggested columns are documented in `docs/REPORTS.md`.

## Deliberately not represented as guessed deployable XML

Agentforce, Prompt Builder, Flow Builder designs, Lightning App Builder page
layouts, Reports, Dashboards, role hierarchy, profiles and sharing rules are
documented as org-configuration steps because these depend on the actual
Salesforce Developer Org and available Salesforce features.

This prevents the repository from containing fabricated metadata that appears
complete but fails in Salesforce.

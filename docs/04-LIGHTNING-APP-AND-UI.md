# Lightning App and UI Specification

Create a Lightning App named:

SwiftShip Tracker

Navigation tabs:
- Shipments
- Routes
- Delivery Attempts
- Delivery Exceptions
- Proof of Delivery
- Reports
- Dashboards

## Shipment Record Page

Include:
- Record details
- Shipment status / milestone
- Route
- Recipient information
- Related Delivery Attempts
- Related Delivery Exceptions
- Proof of Delivery related list

## Route Record Page

Include:
- Route information
- Assigned Delivery Agent
- Planned start/end
- Related Shipments

## Exception Record Page

Include:
- Exception details
- Severity
- Assignment
- Resolution status
- Resolution notes
- Escalation Required
- Related Shipment

## Dashboard Page

Add SwiftShip Operations Dashboard.

Use Dynamic Forms and Related Lists where supported by the Developer Org.
